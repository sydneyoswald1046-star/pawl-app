# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

PAWL — Expo / React Native (TypeScript, strict) invoicing app. SDK 54, RN 0.81, React 19, New Architecture enabled. iOS / Android / web. No backend; all data is in-memory seed data.

## Commands

```bash
npm start          # expo start (Metro bundler + dev menu)
npm run ios        # expo start --ios
npm run android    # expo start --android
npm run web        # expo start --web
npx tsc --noEmit   # typecheck (no test runner configured)
```

There is no lint script, no test runner, and no `build` script — Expo handles bundling. If you need a production build, use EAS (`eas build`) — not configured in repo yet.

## Architecture

### Entry & navigation

- `index.ts` → `registerRootComponent(App)` (Expo entry).
- `App.tsx` wraps the tree in `SafeAreaProvider` → `I18nProvider` → `ThemeProvider` → `NavigationContainer`.
- Two-layer nav: outer **native stack** (`Stack`) wraps inner **bottom-tab** (`TabNav`). Modal screens (`NewInvoice`, `TapToReceive`, `Reminders`, `ClientForm`, `Reports`) live on the stack with `presentation: 'modal'`. Detail screens (`ClientDetail`, `InvoiceDetail`) are normal pushes.
- The center "Create" tab is a **fake tab** — its `tabPress` listener calls `e.preventDefault()` and `stackNav.navigate('NewInvoice')` instead of mounting a screen. The custom dome under the plus button is rendered by `TabBarBackground` (SVG path with a circular cutout).
- A `SplashScreen` overlay sits on top of the navigator until `setSplashDone(true)` is called.

### State (the unusual part)

There is **no Redux / Zustand / Context for data** — `src/data/invoices.ts` and `src/data/clients.ts` each implement a tiny custom store: a module-level mutable array + a `Set<() => void>` of listeners + `useSyncExternalStore` for React subscription. Mutations call `listeners.forEach(l => l())` to notify subscribers.

Implications when editing:
- Always mutate via the exported `addX` / `updateX` / `deleteX` helpers — never reassign the module array directly from outside.
- `useClients()` derives `ClientWithStats` by joining clients with `useInvoices()` inside a `useMemo`. Editing the shape of either store requires updating the `enrich()` join in `clients.ts`.
- Clients are joined to invoices by **`client.name === invoice.client`** (string match, not id). Renaming a client without also rewriting its invoices' `client` field will desync stats.
- All seed data lives at the top of these files. Reset = reload Metro.

### Theming

`src/theme.tsx` exports a `ThemeProvider` with a hardcoded `dark`/`light` palette and a `useTheme()` hook returning `{ dark, toggle, c }`. Default is **dark**. The Navigation theme in `App.tsx` is derived from `c` so screens, tab bar, and headers all share the same palette. `getTierColors()` returns earnings-tier accent colors used by the dashboard.

### i18n

`src/i18n/index.tsx` — flat-key dictionary (`en.ts`, `es.ts`). `TranslationKey` is the union of `en.ts`'s keys, so **`en.ts` is the source of truth**; missing Spanish keys silently fall back to English in `t()`. `useT()` returns `t`; `tPlural(t, baseKey, count)` picks `${baseKey}_one` / `${baseKey}_other`. Initial locale is detected from `expo-localization`. The data layer reads the current locale via the module-level `getCurrentLocale()` (not the hook) so it can format dates outside React.

### NFC / Tap to Receive

`src/lib/nfcCapability.ts` returns `'builtin' | 'external' | 'unsupported'`. iPhone XS (`iPhone11,*`) + iOS 16.4+ → builtin (Tap to Pay on iPhone). Older iPhones, iPads, Android → external reader. Simulator/dev → forced `'builtin'` so the flow is testable. There is **no real NFC integration yet** — `TapToReceiveScreen` is UI only.

### Components

`src/components/` holds shared visual pieces only (`TabBarBackground`, `LifeLine`, `PulseGlow`). Screens are flat under `src/screens/` — no per-feature folders. `react-native-reanimated` + `react-native-worklets` are configured (the worklets babel plugin is required in `babel.config.js`); animations use Reanimated 4 APIs.

## Conventions worth knowing

- **Strict TS**, React 19, no path aliases — imports are relative.
- Dates everywhere are ISO `YYYY-MM-DD` strings (not `Date`). Helpers in `invoices.ts` (`daysUntilDue`, `isOverdue`, `formatDateShort/Long`, `formatDueStatus`) handle parsing and locale formatting — reuse them rather than rolling new date math.
- Invoice numbers are generated by `nextInvoiceNumber()` scanning existing invoices for the max trailing integer.
- New screens: add the component file under `src/screens/`, then register it in `App.tsx`'s `Stack.Navigator` (or as a `Tab.Screen` for tabs). Modals use `options={{ presentation: 'modal' }}`.
- New translation keys: add to `en.ts` first (extends `TranslationKey`), then mirror in `es.ts`.
